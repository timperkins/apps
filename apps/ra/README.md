# RA

A pixel-art real-time strategy game at [ra.trom.dev](https://ra.trom.dev), for up to eight players on the same network, or one against the computer.

- **Multiplayer** (the landing page, `src/lobby.ts`): a world drifts by behind it (a single-player world with both bases, drawn but never run). Enter a name (remembered on this device), then **Host a game** to get a four-letter room code, or type someone's code and **Join**. The room shows its code at the top and everyone in it; each player is given a color nobody else has (twelve to choose from) and can change it there. The host picks one of the maps made for that many players (the previews show every place a player can start), **Shuffle** for other versions of them, and **Start**. Each player starts with a Foundry vehicle and an escort at one of the map's starts, every side builds its own base, and a player with nothing left is out; the last one standing wins. **Test mode** at the top right goes to the game against the computer and its test stages, at `/test` (also `?solo`). In a game, the menu's **Leave game** goes back to the lobby.
  - **Bots**: the host can **Add bot** in the room (as many as there are free places) and pick each bot's difficulty and color, or take it out. A bot runs on the host's screen (`src/v2/bot.ts`) and plays through the same orders a player gives, one decision every couple of seconds: it deploys its Foundry, builds up a base, keeps its Barracks and Vehicle works busy, and every so often sends the army it has gathered against the nearest enemy base. Easy thinks every 4s, gathers 4 units and first attacks after 7 minutes; Normal 2.5s, 6 units, 5 minutes; Hard 1.5s, 8 units, 3.5 minutes, with a bigger base.
  - **Coming back**: a room has its own address, `/CODE` (Firebase Hosting sends every path to `index.html`), so reloading the page brings you back in. A player joins again (and, in a game, makes the world again and carries on with their side). The host saves the room, and in a game the latest update every two seconds and when the page goes, in local storage (`ra-host-CODE`); after a reload it takes the room back up and carries on from there (`IsoGame.restore`). While the host is away everyone else's game is paused; they keep trying to get back for three minutes before giving up.
  - **How it connects**: browsers can't find each other on a network by themselves, so the WebRTC handshake (an offer from each joining player, an answer from the host) goes through a room document in Firestore (the `ra-rooms` database, `ra-rooms-preview` for previews; rooms and their handshakes expire after six hours). Once a player's data channel is open, everything goes straight between the devices (`src/net/`). `?localnet` passes the handshake between tabs of one browser instead, for testing.
  - **How it stays in step**: the host's screen runs the game for everyone. Each player's orders (moves, attacks, building, placing, deploying...) go to the host as commands (`Command` in `src/v2/game.ts`), and ten times a second the host sends everyone how things stand: every unit and building, what was destroyed, each player's credits and build queue, and the ore now and then. Players' screens run the same game in between, so movement and gunfire stay smooth, and ease each unit towards where the host has it; only the host decides what gets hit, built or destroyed. A player's own move and attack orders show on their screen at once. This is used rather than lockstep (every screen running the game exactly in step) because the game uses floating point and random numbers throughout and runs on phones and computers with different browsers, which would drift apart.
  - Limits for now: the host's tab has to stay open and in front (a phone that locks or switches apps pauses the game for everyone), and if the host closes the room the game ends. A player who leaves leaves their units behind.

- **Picking a map**: when the game loads (and on **New map** in the menu) you pick one of twenty maps, each shown as a little picture with your start and the enemy base marked and tagged with how many players it is made for (2P up to 8P); **Shuffle** shows other versions of them. The maps are recipes in `src/v2/maps.ts`: each gives the share of water and high ground, an optional mask that shapes the land (islands, belts, rings, rivers with fords, seas, continents joined by bridges), the player counts it suits and up to eight starts, of which `startsFor` picks the ones furthest apart for a game. `src/v2/maps.test.ts` checks, over several seeds, that every start is on land joined to all the others. Long Isle (one long island, for testing) comes first, then Equator, Lakelands, Highlands, Trident, Isthmus, Crossroads, Serpent, Fjords, Riverlands, Inland Sea, Atoll, Wetlands, Six Seas, Badlands, Crater Lake, Pangaea, Two Continents, Meridian and Grand Plains.
- **Loading screen**: once you pick a map, a pixel-art loading screen (a little tank rolling along a progress bar) stays up while the world is made and its art is drawn, so play starts smoothly instead of stuttering for the first few seconds. The unit and building pictures are drawn by the voxel renderer, which takes a few milliseconds per unit heading and up to a few hundred per building on a phone; rather than drawing them mid-game they are drawn off the main thread by a few web workers (`src/v2/art-pool.ts`, `src/v2/art-worker.ts`). The screen waits for the bases, the globe's map and the headings the nearby units start out with; the rest of the headings follow in the background, and a heading not ready yet borrows the nearest one that is for a frame or two. Without workers (or `OffscreenCanvas`) everything is drawn on the main thread as before.
- **Stage** (for testing): buttons above the maps pick how the game starts, and the last pick is remembered.
  - **Initial**: the normal start, below.
  - **Combat**: straight into a fight. You get a full base of your own (Foundry, everything on the tech tree, power plants to run it and a hauler at work), an army the size of the enemy's and $50000 (you can hold $100000), about a screen and a half from the enemy base. The enemy keeps its army up to strength: whenever it is short of a kind, its Barracks, Vehicle works or Helipad makes another, for free, until that building is destroyed. Its units wait in groups of four at six posts round its base, with new ones gathering by its Foundry until there are enough to fill a gap. They fight whatever comes near but never go looking for a fight. The enemy's side is in the "The enemy (Combat stage)" part of `src/v2/game.ts`.
- The world is a small planet, about fourteen screens across (10240 × 5120 map pixels, half the area it used to be): a procedurally generated landscape of grass, rocky ridges, forests, lakes and oceans with beaches and shimmering surf, and a dirt road from your start to the enemy base. Each map shapes the land with a mask added to the lake noise and its own share of water and high ground (`LandShape` in `src/v2/terrain.ts`). It is far too big to paint at once, so the ground is classified and painted in 128-pixel tiles as they come into view, a few each frame (`src/tiles.ts`), with a coarse overview of the whole map filling in until they are ready.
- The world wraps round in every direction: pan any way and you come back round, with the land flowing on seamlessly and everything the same way up (terrain noise is periodic both ways: `wrapNoise` and `WorldField` in `src/gfx.ts`). Units go the way you panned, so you can attack from either side.
- Zoom out past half size and you whoosh up through the atmosphere into space, where the world is a hazy, cloudy globe (`src/planet.ts`) with the map wrapped round it from the point under the camera, so panning slides the map round the globe without stretching it. The globe starts out bigger than the screen and keeps shrinking as you zoom out. It shows the overview of the map: lakes, roads, forests as darker land, the bases themselves, and units as dots of their colour. Drag it to spin it. Tap it to fly down, or, with units selected, to send them there the shortest way.
- At normal zoom a minimap globe sits at the top right with the view outlined. Drag it to spin the world quickly, or tap it to jump there.
- You play Cobalt, and you start with a handful of units and no base: a **Mobile Foundry** (a big tracked vehicle with a crane folded on top), two Lancer tanks, a Scout buggy and three Riflemen (in v2; v1 still starts with ready-made bases). The enemy, Ember, is dug in on the far side of the planet with a full base (Foundry, HQ, vehicle works, power plants, barracks, refinery, silo, radar, helipad, gun towers) and an army: tanks, scout buggies, an ore hauler, artillery, a copter, infantry and patrol boats. The enemy has no plan of its own yet, but it fights back (see **Combat**). You only command your own side: tap an enemy unit or building to see its health, outlined in red.
- **Water**: ground units can't drive into water (lakes or the sea) and boats can't leave it. Heading into the shore they slide along it towards where they were sent, and give up when that gets them nowhere; there is no proper pathfinding yet.
- **Deploying the Foundry**: select the Mobile Foundry and its footprint shows on the ground, green where it can deploy (open, level grass clear of roads, water and other buildings) and red where it can't. Tap **Deploy** above the toolbar (or tap the vehicle again, or press F) and it lines up, anyone standing in the way drives off, and the Foundry rises out of the ground, clearing the trees. Tap the Foundry to select it and **Pack up** folds it back into the vehicle, so you can move your base.
- **Building your base**: once the Foundry stands, **Build** appears on the toolbar and your credits ($5000 to start, shown at the top) appear next to the menu button. The build menu is a wooden-framed panel in the game's pixel style: on a phone **Build** opens it as a sheet above the toolbar (B toggles it), and on a wide screen it is a sidebar under the minimap that is always open. Your credits sit at the top with a gold coin (prices show the coin too), a power bar runs down its left side (segments for what your plants make, a white notch for what your base uses; yellow when it is tight, blinking red when you are short), and the tabs are a single row of little pictures drawn from the game's own models (a Power plant, a Gun tower, a soldier, a tank). It lists only what you can build right now, each as a close-up "action shot" in the style of the old RTS build pictures: the building or unit drawn big and in extra detail (the renderer's `scale` option in `src/v2/stack.ts`), in front of its own landscape from the game (meadow, pine forest, rocky ridge, lakeshore, dusk, ore field, dry highlands or a smoky battlefield) with dust, smoke, tracers or a spinning rotor (`src/v2/cameo.ts`). Foot soldiers get a detailed head-and-shoulders portrait instead of their tiny map figure (`src/v2/portrait.ts`). The pictures are drawn one at a time in the background, with a plain picture standing in until each is ready. The coin and bolt icons are in `src/pixel-icons.ts`. Tap an item to start it: its icon darkens and a clock wipe sweeps round as the credits drain. Tap it again to put it on hold, and hold it (or right-click) to cancel and get your credits back. Each tab builds one thing at a time. When a building is ready, tap it and a see-through ghost of it goes on the map, green where it can stand (open, level ground within a short gap of the rest of your base) and red where it can't. On a phone, tap or drag to move it and press **Place**; with a mouse it follows the pointer and a click puts it down (right-click or Esc to put it back for later). It rises out of the ground.
- **The tech tree**: each building opens up more. Foundry → Power plant → Barracks and Ore refinery; Barracks → Gun tower; Refinery → Ore silo, Vehicle works and Radar mast; Radar → Helipad; Vehicle works + Radar → Tech lab. New options get a **New** badge and a message. The tree is in `src/v2/tech.ts`.
- **Training units**: the Barracks opens the **Infantry** tab (Riflemen, Rocketeers) and the Vehicle works the **Vehicles** tab (Scout buggy and Lancer tank; Ore hauler with a refinery; Howler artillery with a radar; Bastion tank with a Tech lab; another Mobile Foundry), and a Helipad plus a Tech lab add the Kestrel copter. Units queue up: tap an item once per unit (up to 5 of each, the count shows on the icon) and hold it to take one off. Each tab makes one unit at a time; it drives out of the door, or lifts off the helipad. Select a Barracks, Vehicle works or Helipad and tap the ground to set its **rally point**, shown as a flag, where its new units go (**Clear rally** removes it). With two of the same kind, **Make primary** picks which one they come out of.
- **Ore and credits**: fields of golden ore grow round the planet, two of them near where you start, one by the enemy base and one half way: low heaps of rough nuggets on ore-stained earth, packed close so a field reads as a lumpy carpet. Every Ore refinery comes with a free Ore hauler, which finds the nearest ore, digs a load, drives it back to the refinery's striped pad and unloads it for credits, over and over. Clumps shrink as they are dug and creep back slowly unless dug out completely. Its bed shows how full it is: empty, a low heap of ore, or heaped full. Send a hauler somewhere else and it stops work; send it onto ore and it starts again. With a hauler selected the pointer over ore turns into a gold diamond closing in on a nugget, the attack gunsight's cousin, with a gold burst on click (on a phone, the confirm check is gold inside the diamond). Haulers only ever go after ore, never enemies. You can only hold so many credits ($3000, plus $2000 per refinery and $3000 per Ore silo); when you are full, haulers wait at the refinery until you spend some or build a silo.
- **Combat** (`src/v2/combat.ts`): every weapon has a warhead and every unit and building an armour type, and a table says how much gets through: small arms shred infantry and barely scratch tanks, armour-piercing rounds are the other way round, and high explosive is good against buildings. Each weapon has its own damage, reload and range (in cells, about a tank's length), and only rockets and the Bastion's twin 105mm can hit the copter. Units standing about fire on the nearest enemy in range (gun towers too), a unit that is hit turns on whoever hit it and its friends nearby come to help (chasing only so far before going back), and a unit sent somewhere doesn't stop to fight. With units selected, tap an enemy (or right-click it) to attack it: the pointer turns into the move cursor's four arrowheads in red and they close in until it is in range. Direct-fire rounds land all over the target, not just its middle (`HIT_SPREAD` in `src/v2/combat.ts`). Rounds fly as tracers, shells, rockets with smoke trails or lobbed artillery shells that burst over an area; guns flash and kick back, and whatever is hit flashes and shows its health for a moment. Soldiers are knocked back a little by every hit, and tanks by heavy rounds (the Bastion's shells and artillery bursts), away from where the round came from (`knockback` in `src/v2/combat.ts`).
- **Destruction**: a damaged vehicle smokes from two thirds health, wisps at first, thickening to a dark column as it nears the end (`Fx.damageSmoke`). Anything destroyed blows up and breaks into small solid black pieces (its own shape cut up, `Fx.wreck` and `Fx.shatter` in `src/v2/combat.ts`), which land round it and fade away in about a second, while thick smoke rolls up and a column of it keeps rising from the spot for a few seconds; a copter's chunks rain down from the sky. Tanks cook off in a string of explosions with a fountain of embers. A building below half health is holed, scorched and on fire; when it is destroyed it goes up in a string of explosions, breaks into chunks under a cloud of smoke and leaves a ruin, which smokes for half a minute or so and stays for good. When a tank or a building is destroyed the view shakes a little, most when it is in the middle of the screen, not at all when it is off screen, and less the further out you zoom (`shake()` in `src/v2/game.ts`, applied in `src/main.ts`). The damaged buildings and ruins are drawn from the same models as the buildings (`makeBuildingStates` in `src/v2/sprites.ts`).
- **Power**: Power plants make power and most other buildings use it. The build menu shows power used / made; when you use more than you make, the credits at the top turn red with a ⚡ and everything builds at half speed until you build another Power plant. The numbers are in `src/v2/tech.ts`.
- **The shroud** (`src/v2/shroud.ts`): everything you haven't seen yet is black, the enemy base and army included. Your units and buildings lift it round themselves as they go (scouts, copters and the Radar mast see furthest) and it stays lifted for good, with a soft faded edge. Enemy units under it can't be seen, picked or targeted, and the minimap and the globe show only what you have explored. Add `?noshroud` to the URL to play without it.
- **Moving round and selecting**: on a phone, drag to pan. Tap a unit to select it, or tap a building to select it and see its health. On a computer, drag a box to select several (WASD or the arrow keys pan).
  - **Select** on the toolbar (Q) opens the selection menu above it; selecting something opens it too. It is always one row: the colour groups and the unit buttons scroll sideways when there are too many, and **Group** and **All**/**Clear** stay put at the right. It has a button for each kind of unit of yours on screen, with a bubble saying how many there are: tap one to add them all to the selection (it lights up green), tap it again to take them out. You can have several kinds selected at once. **All** selects everything of yours on screen except ore haulers, so they stay at work (unless haulers are all there is; tap the hauler button to add them); once anything is selected it gives way to **Clear**, which deselects (they share one spot, so the bar doesn't shift).
  - A selection made with the menu is locked as a group (below) as soon as you pan away or tap the map, so the units that go off screen stay in it.
  - **Colour groups**: with units selected, **Group** opens eight colours above the menu (Shift+1-8 with a keyboard); pick one to make the selection that colour's group (a unit is in one group at most). The groups in use show at the front of the menu as buttons in their colour with how many units are in them: tap one (or press 1-8) to select that group again wherever its units are, and tap it again to go to them. Selected units in a colour group have their selection corners in its colour, and so does the Group button's icon. A selected colour group shows only as its own button, not twice.
  - With units selected, tap the ground to send them there or an enemy to attack it. On a phone a round green check comes up where you tapped, with the move cursor's green arrowheads turning round it (for an attack, a red check with the attack cursor's red arrowheads): tap the check to send them, or somewhere else to move it. Clear the selection to call it off. With a mouse a click sends them straight away. Units on their way somewhere you sent them show a faint green line out to where they are going. Once you have sent them, the selection is locked as a group: the menu shows them as one button with the picture of their most common kind and how many there are in all (tap it to go to them), in a dashed frame, and taps and clicks send them again, even onto your own units. Clear (or Esc) to pick something else.
  - **Home** takes you back to your base (the Foundry, or the Foundry vehicle before it deploys).
- Pinch to zoom on a phone (two fingers also pan); on a computer, scroll to zoom around the cursor, or use + / - / 0.
- On a computer: shift adds to the selection, right-click moves (or attacks), middle-drag, WASD or the arrow keys pan, Q opens the selection menu, 1-8 picks a colour group and Shift+1-8 makes the selection one, Ctrl+A selects everything on screen but the ore haulers, F deploys the Foundry, H goes home, B opens the build menu, Esc clears.
- The menu button at the top left holds **New map**, which picks a map for a fresh world, and the version picker, which switches versions (also `?v=1` / `?v=2` in the URL; the last pick is remembered):
  - **v2 · Isometric** (default): 2:1 isometric view with raised plateaus and rock faces, and every unit, building, tree and prop drawn as a shaded voxel shape with cast shadows (`src/v2/`).
  - **v1 · Top-down**: the original straight-down oblique view (`src/v1/`).

No collision yet, and cliffs don't block units yet. The showcase at `/units/` shows every unit and building attacking, being hit, being destroyed (flying to pieces, and a building's ruin), and damaged. All art is drawn in code (`sprites.ts` and `terrain.ts` in each version's folder) and scaled up with nearest-neighbour filtering.

**How v2's art is drawn**: every unit, building and prop is a little model, a function from a point in space to a colour (`src/v2/sprites.ts`), which `src/v2/stack.ts` turns into a sprite by casting a ray per pixel. It lights each surface by which way it faces (so round things shade in bands), lets parts cast shadows on each other and the ground, darkens corners, and draws a lit rim and a dark line where one part stands in front of another. The art is drawn at twice the map's own grid (`ART` in `src/gfx.ts`): things are the same size on screen as before with pixels half as big, which is what leaves room for hatches, road wheels, window frames, roof clutter, courses of stone in the cliffs and blades of grass. The ground is painted to match (`paintSteps` in `src/v2/terrain.ts`), a few rows per frame so that painting a tile never holds up a frame. v1 is still drawn one for one.

**Sound** (v2): guns, shells, explosions, wrecks, engines, rotors, footsteps, building, ore and the buttons, from 32 clips in `public/sfx/` made with ElevenLabs (`src/sfx.ts`). A sound is as loud as it is near the middle of the view, quieter zoomed out and nearly silent from space; one clip often stands in for several (pitched up or down, doubled for twin barrels, or played backwards). 

**Settings** (menu → Settings, `src/settings.ts`): sliders for Music, Sounds and Voices volume (0 turns one off) and for keyboard Scroll speed and wheel Zoom speed. They are saved in localStorage under `ra.settings`; the old on/off choices carry over.

```sh
npm install
npm run dev
npm run build
```
